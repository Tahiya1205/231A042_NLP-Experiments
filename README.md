# 231A042 NLP Experiments

This repository contains Natural Language Processing (NLP) experiments for course/project **231A042**.

## Getting started

Clone the repository and add each experiment in its own clearly named folder or notebook. Include any setup instructions and dependencies alongside the experiment so results can be reproduced.

## Repository structure

- `experiments/` — NLP experiment code and notebooks
- `data/` — local datasets (do not commit private or large source data)
- `results/` — generated outputs, metrics, and visualizations

## Notes

Document the dataset source, preprocessing steps, model configuration, and evaluation metrics for every experiment.
